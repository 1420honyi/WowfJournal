# 永恆旅誌 WowfJournal

魔獸世界「永恆」繁體中文資料與戰鬥輔助插件，目前版本 **0.3.17**，適用介面版本 **16001**。

## 安裝

1. 關閉遊戲，下載 [最新安裝 RAR](https://github.com/1420honyi/WowfJournal/releases/latest)。
2. 將 RAR 中的 `WowfJournal` 資料夾解壓到遊戲的 `Interface/AddOns`。
3. 確認路徑為 `Interface/AddOns/WowfJournal/WowfJournal.toc`，重新啟動遊戲。

RAR 不需要密碼。內附 Windows 執行環境，不需要另行安裝 Python；不同電腦與帳號可使用，不包含發布者的帳號、角色設定、WTF 或快捷鍵。

## 之後如何更新

關閉遊戲後，在 `WowfJournal` 資料夾內雙擊 **永恆旅誌－更新插件與資料.cmd**。工具先檢查本儲存庫的最新正式版本，驗證下載檔案，再更新插件程式並檢查 WOWF 網站資料。原有角色設定與快捷鍵保存在遊戲的 WTF 中，更新工具不改動它們。

只需要網站資料時，可執行 **永恆旅誌－更新資料.cmd**。**永恆旅誌－啟動並更新.cmd** 會在成功更新後開啟原本的暴雪啟動器。

首次使用線上版本更新，需要安裝本次包含新版外部工具的 RAR。舊分享包的資料更新工具只更新網站內容，不會自行取得新的插件程式。未來只有發布者正式發布新版後，工具才會取得該版本；最新正式版本相同時不重複下載程式包。大型程式包下載會顯示進度，容許較慢的連線；仍有大小上限、連線閒置逾時與整體 30 分鐘上限，下載不完整時保留原版本。

## 功能

- 副本與野外地圖、首領掉落、稀有怪位置、任務、職業天賦與裝備、專業配方及資料搜尋。
- 原生一鍵增益、緊湊驅散格、稀有怪與帶名任務怪偵測、隊伍仇恨顯示。
- 保留官方介面，提供獨立浮窗、透明度、圓鈕配置與戰鬥輔助位置設定。

部分偵測、仇恨資訊與戰鬥施法受遊戲 API、可見單位與保護機制限制；插件不能讀取遊戲未提供的資訊，也不能按一次自動連續施法。網站資料来源為 [WOWF](https://wowf.io/tw)，遊戲素材權利屬原權利人。

更新檔、版本清單及 SHA256 校驗檔在 [Releases](https://github.com/1420honyi/WowfJournal/releases)。更新 ZIP 供外部工具使用，首次手動安裝請下載 RAR。
