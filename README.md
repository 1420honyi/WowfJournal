# 永恆旅誌 WowfJournal

魔獸世界永恆的資料與戰鬥輔助插件。目前正式版本：**0.3.44**。

[下載完整插件](https://github.com/1420honyi/WowfJournal/releases/latest/download/WowfJournal-0.3.44.rar) · [版本及驗證說明](https://github.com/1420honyi/WowfJournal/releases/latest)

## 安裝與更新

首次安裝請完整關閉遊戲，下載免密碼完整 RAR，把其中 **WowfJournal** 資料夾解壓至遊戲的 **Interface/AddOns**。正確位置是 `Interface/AddOns/WowfJournal/WowfJournal.toc`，不需另外安裝 Python 或 Decursive。

已安裝完整版（0.3.18 或以後）可沿用先前的 **EXE 1.0.0** 或插件內的 **永恆旅誌－更新插件與資料.cmd**，二選一執行。兩者共用更新流程：先下載 GitHub 最新正式插件，再抓取 WOWF.IO 網站新資料。每次更新都保留自己的 WTF、銀行、拍賣資料與快捷鍵。

**EXE 小包不是完整安裝器**，單獨傳 EXE 給未安裝插件的人，無法完成首次安裝。曾使用 addon-only 手動包、沒有 Tools/Runtime 的使用者，也請先安裝完整 RAR。舊 EXE 未簽章，Windows 仍可能封鎖；不需關閉安全防護，遇到封鎖可下載完整插件手動安裝。

遊戲內 **其他資料 → 資料更新 → 載入最新資料** 只讀取外部工具已下載的檔案，不會自行連線抓網站。程式或材質更新後請完整重開遊戲；網站資料更新完成後可依遊戲內提示重載。

## 功能

- 可移動的小地圖圓鈕、冰霜收納與羊皮紙資料窗。
- 副本地圖、王與掉落、副本任務與接取位置、全部職業指南、搜尋。
- 生活助手：採集試作、全部專業配方與練級指南。
- 採集試作：小地圖草礦縮圖、官方懸停名稱、近處物件循環光圈與閃光；需要官方資源追蹤及客戶端可用的互動資訊。場景提示非任意距離偵測，也無法精確固定地面碼數、沿模型描邊或判斷牆壁遮擋。
- 稀有與帶名任務怪偵測、原生增益與驅散小格、組隊仇恨。施法仍需使用者按鍵，資料以客戶端公開 API 可用範圍為準。
- 買賣資料庫：拍賣掃描、分類搜尋、可信價格、包包及銀行提示；同帳號同服共用，跨服分開保留。
- 角色銀行：右鍵官方包包圖示查看同服角色已記錄的銀行，職業色與物品說明；須以該角色先開過銀行。
