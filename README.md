# 永恆旅誌 WowfJournal

魔獸世界永恆的資料與戰鬥輔助插件。目前正式版本：**0.3.30**。

[下載最新版](https://github.com/1420honyi/WowfJournal/releases/latest)

## 安裝與更新

首次安裝請完整關閉遊戲，下載 Release 內的免密碼 RAR，把其中的 **WowfJournal** 資料夾解壓到遊戲的 **Interface/AddOns**。

正確位置是 `Interface/AddOns/WowfJournal/WowfJournal.toc`。不需要另外安裝 Python 或 Decursive。

日後更新只需完整關閉魔獸，執行插件資料夾內的 **永恆旅誌－更新插件與資料.cmd**。它會先下載正式插件新版，再更新 WOWF 網站資料。完成後照平常方式開啟遊戲；各人的介面設定、快捷鍵、銀行與拍賣保存資料沿用。

遊戲內的資料更新頁可重新載入外部工具已下載的網站資料。新增程式模組或圖片後請完整重開遊戲。

## 功能

- 小地圖旁的可移動圓鈕、冰霜收納與羊皮紙浮窗。
- 副本地圖、王與掉落、副本任務及接取位置、職業天賦與裝備、專業配方、資料搜尋。
- 野外稀有怪與帶名任務怪偵測、原生增益與驅散小格、組隊仇恨提示。施法仍需玩家按鍵操作，資訊依遊戲公開 API 可用範圍顯示。
- 買賣資料庫：在拍賣場更新並保存可信價格，野外可從包包或銀行物品說明查看。同帳號同服角色共用，跨服分開保留。
- 角色銀行：右鍵官方包包圖示開啟，查看同服角色保存的銀行格子與物品說明；角色名稱採官方職業色。只供查看，須先以該角色開啟銀行一次。

預設官方小地圖、地圖探索紀錄與既有操作介面保留。
